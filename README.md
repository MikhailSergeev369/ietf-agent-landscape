# IETF Agent-Related Work Landscape

A community-maintained catalogue of Internet Engineering Task Force (IETF) working groups, Birds of a Feather (BoF) sessions, mailing lists, and Internet-Drafts related to AI agent standardization.

**Current snapshot**: [agent-standards-landscape.md](agent-standards-landscape.md) (July 2026)

## What this is

The volume of agent-related work at IETF has grown to the point where no single participant can hold the full picture in mind. Charter reviews, BoF discussions, and adoption decisions benefit from a shared inventory. This repository provides that inventory as a continuously updated reference.

As of July 2026 the landscape covers:

- **225 unique Internet-Drafts** organized across 17 categories
- **9 chartered IETF working groups** touching agent-related work
- **8 BoFs and research groups** including three WG-forming BoFs at IETF 126
- **10+ mailing lists and coordination venues**

## What this is not

This document does not advocate for any particular proposal. It attempts to inventory what exists so that architectural conversations about scope, overlap, and layer placement can happen with a shared map.

The document takes editorial choices about categorization that some contributors may disagree with. Those disagreements are welcome as issues or pull requests.

## How to contribute

**File an issue** if you notice:
- A missing draft or venue
- An incorrect categorization
- An outdated entry (superseded draft, renamed venue, expired document)
- A factual error in a description

**Open a pull request** for:
- Additions of drafts, venues, or coordination efforts
- Corrections to descriptions or authorship
- Improvements to category descriptions

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed contribution guidelines.

## Categories

The landscape is organized into 17 categories. Each category has three subsections: IETF venues, IETF work items, and external protocols/industry references.

1. Identity, Auth & Attestation (52 drafts)
2. Discovery, Naming & Directories (22 drafts)
3. Agent-to-Agent Communication (17 drafts)
4. Agent-to-Tool / API Invocation (6 drafts)
5. Semantic Intent, Verb Taxonomies & Action Description Layers (6 drafts)
6. Multi-Agent Collaboration & Gateways (19 drafts)
7. Human-in-the-Loop, Oversight & Confirmation (8 drafts)
8. Audit & Accountability (31 drafts)
9. Agent Transport & Connectivity (1 draft)
10. Security & Threat Modeling for Agent Protocols (11 drafts)
11. Agentic Commerce (5 drafts)
12. AI Content Preferences (2 drafts)
13. Bot/Crawler Authentication (2 drafts)
14. AI Networking, Ops & Agent Networking (21 drafts)
15. Coordination, Problem Framing & Architectural Principles (8 drafts)
16. Agent Packaging, Manifests, Integrity Verification & Unified Lifecycle Management (2 drafts)
17. Agent Bindings & Composition (6 drafts)
